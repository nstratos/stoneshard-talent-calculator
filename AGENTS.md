# Repository instructions

## Architecture

The app currently uses browser-native HTML, CSS, JavaScript modules, and custom
elements. This architecture is intentional and keeps the project simple and
close to the web platform.

Use the current architecture for scoped changes. Treat frameworks, TypeScript,
and build tooling as project-level decisions. Evaluate them for their effects on
maintainability and contributor experience. Established frontend practices are
welcome when they improve the project.

## UI changes

Read the [UI design guide](docs/ui-style-guide.md) before making UI or CSS
changes. Follow its design direction and review guidance.

## Development workflow

Follow the setup and validation instructions in
[Local Development](README.md#local-development).
